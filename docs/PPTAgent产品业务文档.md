## 1. 产品概述

### 1.1 产品定位

PPT Agent 是一款基于人工智能技术的 PPT 自动生成工具，旨在帮助用户从已有的文档资料中快速生成可用于演讲的 PPT 文件，解决重复制作 PPT 的劳动成本问题。

### 1.2 核心价值

- **资料来源可靠**：与传统 AI 生成 PPT 产品不同，本产品的所有 PPT 内容均来源于用户提供的可靠资料，确保信息的准确性和专业性
- **快速生成**：用户只需提供文档，即可自动完成 PPT 的结构梳理、内容排版等繁琐工作

### 1.3 差异化优势

目前市场上存在的 PPT Agent 产品大多基于用户提供的关键词或大纲，由大模型自行发挥生成内容。这种方式在专业领域容易出现信息不准确的情况。本产品通过严格遵循用户提供的原始资料，确保生成内容的准确性和可信度。

## 2. 目标用户

| 用户类型 | 使用场景           | 核心需求           |

## 3. 功能需求

### 3.1 核心功能

#### 3.1.1 文档输入

- **直接文本输入**：用户在界面直接粘贴或输入文本内容
- **文件上传**：支持上传 Word（.docx/.doc）、PDF、纯文本（.txt）等格式的文件
- **无长度限制**：对输入文档的字数没有硬性限制

#### 3.1.2 AI 智能分析

系统对用户输入的文档进行智能分析，输出以下要素供用户确认：

| 输出要素   | 说明               |
| ------ | ---------------- |
| PPT 标题 | 根据文档内容提取或生成的主题标题 |
| 分页结构   | PPT 的页面划分和逻辑结构   |
| 内容梳理   | 每页的核心要点和大纲       |
| 梳理结果   | 整体内容的结构化呈现       |

#### 3.1.3 用户确认与修改

- AI 分析结果对用户可见
- 用户可以在生成 PPT 前对分析结果进行确认或修改
- 确保输出内容符合用户预期

#### 3.1.4 PPT 生成

- **输出格式**：标准的 .pptx 文件格式
- **内容形式**：
  - 文字内容（标题、正文）
  - 思维导图等结构化展示形式
- **暂不包含**：图片、动画等元素

#### 3.1.5 PPT 模板

- **模板数量**：预计提供 10 种左右模板风格
- **默认模板**：空白基础模板
- **风格选择**：用户可自主选择不同的模板风格（具体风格待定）

#### 3.1.6 下载功能

- 用户可直接下载生成的 PPT 文件
- 无数量限制，可自由生成

#### 3.1.7 历史记录

- 自动保存用户的生成历史记录
- 方便用户回顾和重复使用

### 3.2 功能列表

| 序号 | 功能模块   | 功能描述               | 优先级 |
| -- | ------ | ------------------ | --- |
| 1  | 文本输入   | 支持直接粘贴或输入文本        | P0  |
| 2  | 文件上传   | 支持 Word、PDF、TXT 格式 | P0  |
| 3  | AI 分析  | 智能分析文档，输出结构化结果     | P0  |
| 4  | 用户确认   | 用户查看并修改分析结果        | P0  |
| 5  | PPT 生成 | 根据确认的内容生成 PPT      | P0  |
| 6  | 模板选择   | 提供多种模板风格供选择        | P0  |
| 7  | 下载功能   | 下载生成的 PPT 文件       | P0  |
| 8  | 历史记录   | 保存和查看历史生成记录        | P1  |
| 9  | 思维导图   | 生成思维导图展示           | P1  |

## 4. 用户流程

### 4.1 完整工作流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  输入文档  │ -> │  AI 分析  │ -> │ 用户确认  │ -> │ 生成 PPT │ -> │  用户下载  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 4.2 流程说明

1. **输入文档**：用户通过文本输入或文件上传的方式提供原始文档
2. **AI 分析**：系统对文档进行智能分析，提取关键信息并生成 PPT 结构
3. **用户确认**：用户查看 AI 分析结果，根据需要进行修改和确认
4. **生成 PPT**：系统根据确认的内容，结合用户选择的模板生成 PPT 文件
5. **用户下载**：用户下载生成的 PPT 文件进行使用

### 5.1 技术选型

| 技术项    | 选择          | 说明                   |
| ------ | ----------- | -------------------- |
| 开发语言   | Python      | 主开发语言                |
| AI 框架  | LangChain   | 用于构建 AI 应用           |
| AI 模型  | MiniMax API | V1.0 版本使用，支持后续扩展其他模型 |
| PPT 生成 | python-pptx | Python 生成 PPT 的标准库   |
| 应用形态   | 桌面应用        | 纯本地运行，无需服务器          |

```
┌─────────────────────────────────────────┐
│              用户界面层                  │
│         (桌面应用界面)                    │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│             业务逻辑层                   │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐ │
```

## 6. 版本规划

## 7. 产品特点

### 7.1 优势

- **资料可控**：所有内容来源于用户提供的原始资料，确保信息准确
